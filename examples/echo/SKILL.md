# Echo

- `echo_say`: says the text back, with the project it was said in.
- `echo_shout`: the same, as a paid feature.
- `echo_dot`: draws a dot, returned as a PNG image.
- `echo_confirm`: asks the user first, then says the text back.
- `echo_wait`: waits, then says the text back; a long operation that runs as a task.
